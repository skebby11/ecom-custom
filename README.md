# ecom-custom

Stack ecommerce leggero e self-hosted: alternativa a Shopify/WooCommerce per cataloghi piccoli.

Astro SSR + Fastify + SQLite + Stripe. Vetrina, PLP, PDP, carrello, checkout e pannello di
amministrazione, con zero JavaScript sulle pagine che non ne hanno bisogno.

> 🚧 In costruzione. Il codice arriva in pull request separate, una per componente.
> La documentazione completa (quick start, configurazione Stripe, deploy) atterra con l'ultima.
